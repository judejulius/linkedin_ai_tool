# Community code of conduct

This project welcomes contributors of every experience level and background.
Help others learn, discuss technical tradeoffs respectfully, and accept good-faith
corrections. Critique code and behavior rather than a person's identity or abilities.

Harassment, discriminatory language, threats, sexual harassment, personal attacks,
and sharing another person's private information are not acceptable. Do not post
credentials or private conversations. These expectations apply to issues, pull
requests, discussions and other spaces maintained by this project.

Maintainers may edit or remove harmful content, restrict participation, or ban
participants depending on severity and repetition. Decisions should explain the
behavior at issue and be applied consistently.

Report concerns privately through a maintainer's published contact channel. If no
private channel is listed, ask for one without naming the affected person or sharing
private details publicly. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

This is the project's own concise policy, not an adoption of a separate external code.
